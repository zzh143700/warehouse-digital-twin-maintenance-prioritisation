# Data and Code Availability

The repository contains the executable code, pinned Python dependencies, recorded seeds, generated model and ranking outputs, literature-audit files and automated verification tests used in the dissertation.

NASA C-MAPSS FD001 represents simulated turbofan degradation. Its three input files are retained in `source_data/` for private reproducibility, with SHA-256 hashes recorded in `docs/DATA_PROVENANCE.md`. If the repository is made public, the current NASA redistribution and attribution conditions should be confirmed. If redistribution is not appropriate, remove `source_data/`, retain the hashes and instruct users to obtain FD001 from the NASA Prognostics Center of Excellence repository.

No warehouse operational data, personal data, employer data, confidential records, participant data or live sensor streams are included. The virtual warehouse assets and consequence parameters are author-constructed scenario elements. Downloaded journal PDFs, full abstracts and extracted full-text passages are excluded.
